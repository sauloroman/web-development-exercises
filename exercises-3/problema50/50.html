Conceptos de SQL.

SQL, Structure Query Lenguage (Lenguaje de Consulta Estructurado) es un lenguaje de progracmación para trabajar con base de datos
relacionales como MySQL, Oracle, etc.

MySQL es un intermediario de SQL, es un servidor de base de datos

MySQL permite crear base de datos y tablas, insertar datos, modificaciones, eliminarlos, ordenarlos, hacer consultasy realizar muchas
operaciones, etc., resumiendo: administra bases de datos
