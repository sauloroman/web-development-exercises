    El atributo id

    El id atributo especifica un identificador único para un elemento HTML. Su valor id debe ser único dentro del documento HTML.

    El id atributo se utiliza para señalar una declaración de estilo específica en una hoja de estilos. JavaScript también lo utiliza para acceder y manipular el elemento con el ID específico.

    La sintaxis para id es: escribir un carácter almohadilla (#), seguido del nombre del id. Luego, definir las propiedades CSS entre llaves {}.

    Notas

    Nota: ¡El nombre de identificación distingue entre mayúsculas y minúsculas

    Nota: El nombre de identificación debe contener al menos un carácter, no puede comenzar con un número y no debe contener espacios en blanco (espacios, tabulaciones, etc.).
